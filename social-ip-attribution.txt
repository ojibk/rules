# 需要明确的风险边界，以下限制无法通过代理规则完全解决：
# 基站定位与 Wi-Fi 指纹：快手等平台通过“基站定位 + Wi-Fi 指纹 + IP 地址”三重机制判定归属地，代理只能影响 IP 维度，基站和 Wi-Fi 维度仍然暴露真实位置。
# 账号注册地 / 常用登录地：部分平台在 IP 属地之外，还会参考账号历史行为数据。长期用同一账号在代理节点所在地发帖，行为一致性可能被风控标记。
# X-Forwarded-For 伪造风险：如果代理节点配置不当，平台可能从 X-Forwarded-For 头中读取到最左侧的真实客户端 IP，而非代理 IP。确保代理软件不追加或泄露原始客户端 IP 头。
# 属地刷新延迟：IP 属地并非实时更新，切换代理后可能需要等待一段时间或重新登录才会刷新。

# format: text / mrs
